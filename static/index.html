Welcome

Create a well-researched 45-minute lesson

LessonForge researches the web, books and YouTube, writes an evidence-cited lesson, and checks it with two independent quality-control layers that you review before exporting.

How to use it

  1. Type a title and learning objective on the left (or click a sample), then Generate lesson.
  2. Wait a few minutes while it researches, writes and checks the lesson.
  3. Follow the numbered steps at the top: 1 Sources › 2 Lesson › 3 Fact check › 4 Teaching check › 5 Export. The Next → button at the bottom of each page takes you to the next one.

On the check pages, each suggestion has its own Apply and Dismiss button. Every change is saved as a new version, so nothing is lost (see History).
